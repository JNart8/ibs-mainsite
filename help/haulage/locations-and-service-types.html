Chapter 6

Locations and Service Types

6.1 Locations#

Who can do this

Admin and Operations, under Operations → Locations.

Locations are the pickup and delivery points used on requests and trips. Each has a Name, City, Region and Country (Ghana unless you change it). Add them here with “New Location,” or on the fly with “+ Add” on a request form.

A location that is used on a request or trip can’t be deleted; deactivate it instead so it no longer appears in the lists.

6.2 Service types#

Who can do this

Admin only, under Operations → Service Types.

Service types describe the kinds of work you do, for example general haulage or container transport. Each has a Name, an optional Description and an optional Default Rate/Ton. Choosing a service type on a request is optional, but it lets the Revenue report break your income down by service.

A service type that is in use can’t be deleted; deactivate it instead.
