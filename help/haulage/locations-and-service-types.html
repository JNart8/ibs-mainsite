Chapter 6

Locations and Service Types

6.1 Locations#

Who can do this

Admin and Operations, under Operations → Locations.

Locations are the pickup and delivery points used on requests and trips. Each has a Code, Name, City, Region and Country (Ghana unless you change it). Add them here with “New Location,” or on the fly with “+ Add” on a request or trip form.

The Code is a short, unique tag of 3 to 6 letters or numbers, such as ACC for Accra or TML for Tamale. It’s saved in capitals and shown in front of the name in location lists (for example “TMP — Tema Port, Tema”), so you can find a place quickly by its code. Locations that existed before codes were added were given a suggested code made from their name; check these and change any that don’t suit you.

For a location in Ghana, pick the Region from the list of the 16 regions. For a location in another country, such as a transit point in Burkina Faso, type the region yourself. If an older location’s region doesn’t match the list, its edit form asks you to pick one before you can save.

A location that is used on a request, trip or route can’t be deleted; deactivate it instead so it no longer appears in the lists.

6.2 Routes#

Who can do this

Admin and Operations, under Operations → Routes.

A route is a trip from one location to another, such as ACC → KSI, with its road distance in kilometres. Add one with “New Route”: pick the Origin and Destination, enter the Distance (km), and add any Notes, such as the road to take. Each route can be added only once, and the origin and destination must be different places.

By default each direction is its own route, so Accra → Kumasi and Kumasi → Accra are set up separately and can have different distances and, later, different prices. If your trips are the same both ways, an Admin can switch on “Routes cover both directions” under Administration → Settings → Routes (section 13.2). Routes then show as ACC ⇄ KSI, one route covers trips either way, and the system won’t let you add the reverse of a route that already exists.

Search the list by any location’s code, name or city. A route you no longer use can be deactivated or deleted.

6.3 Service types#

Who can do this

Admin only, under Operations → Service Types.

Service types describe the kinds of work you do, for example general haulage or container transport. Each has a Name and an optional Description. Prices are set on rate cards (section 6.4), which can be set per service type. Choosing a service type on a request is optional, but it lets the Revenue report break your income down by service.

A service type that is in use can’t be deleted; deactivate it instead.

6.4 Rates#

Who can do this

Admin and Finance can add and change rates, under Finance → Rates. Operations can view them under Operations → Rates.

A rate card is an agreed price. Each rate has: the Route it is for (or “All routes”); who it Applies to (everyone, a client group, or one client); optionally a Service Type and a Truck Type (otherwise any); how it is Charged (per trip, per tonne, per kilometre, per bag or per unit); the Rate and Currency; an optional Minimum Charge; and the dates it is Valid From and, optionally, Valid To.

When a request is quoted, the system picks the rate for the request’s preferred pickup date (or today, if there is none), in this order: the client’s own rate, then their group’s rate, then the general rate. At each level, a rate for this route comes before an all-routes rate, and a rate for the request’s exact service type and truck type comes before an “any” one. If no rate fits the service type and truck type, the nearest rate is offered with a warning.

Caution

Who the rate is for is checked before the route. A client’s own “All routes” rate therefore beats every general rate for a specific route: give a client an “All routes” per-km rate, and that client’s Accra → Kumasi trips use it, not the general GHS 5,000 Accra → Kumasi rate. If a client rate is only meant as a fallback, set it for the routes it should cover instead, or don’t create it. The same goes for a client group’s “All routes” rate. The rate form shows this caution when you set up either one.

Caution

A rate for “Any truck” always fits, so it beats a rate set for a different truck type, even one for the exact route. For example, if Tema Port → Tamale only has a Tipper rate and there is a general “All routes, any truck” per-km rate, a Flatbed job on that route is priced per km. Give every truck type you carry on a route its own rate, or check the rate card box on the quote form before sending. Service types work the same way: a route rate set for one service is not used for jobs with another service, which take an “Any service” rate instead. The rate form shows this caution when you choose a route together with a truck type or a service type.

The price is the rate times the weight in tonnes, the route’s distance in km, or the number of bags or units on the request, or the flat rate for a per-trip rate. It is never less than the minimum charge.

Two active rates for the same route, client (or group or everyone), service type and truck type can’t cover the same dates; the system says which rate is in the way. To change a price from a date, give the old rate a Valid To date and add a new rate from the next day. “Copy” starts a new rate from an existing one, dated to begin the day after it ends, which is handy for renewing contracts each year.

A rate used on a quote can’t be deleted; deactivate it or end it instead. Routes, clients, client groups, service types and truck types that a rate uses can’t be deleted either.

A rate can also carry a Return Empty price, for trips where the truck comes back empty: either an amount, or a percentage of the transport price (for example 50%). Leave it blank if the return is free. The rate list shows it under the price as “Return empty.”

6.5 Additional charges#

Who can do this: Admin and Finance, under Finance → Charges. Operations can view them under Operations → Charges.

A charge type is an extra billed on top of the transport rate, such as loading, waiting time, an escort, or port fees. Each has a Name and Description; how it is Charged (per job, per tonne, per kilometre, per bag, per unit, per day or per hour); a Default Amount and Currency, which is what most clients pay (leave the amount blank if it changes every time, as with port fees); and whether it is a Pass-through charge.

A pass-through charge is a cost you pay on the client’s behalf and bill back to them, such as port or border fees. It is shown as “paid on your behalf” to the client and on invoices, and it is kept out of the trip’s profit along with what you paid for it (section 4.8).

To give a client or client group a different price, click “Client & Group Prices,” then “New Price.” Pick the Charge, who it Applies to (a client group or one client), the Amount and Currency, the dates it is Valid From and To, and any Notes. A client’s own price beats their group’s, which beats the charge’s default amount. Prices are picked for the request’s preferred pickup date (or today).

Two active prices for the same charge and the same client (or group) can’t cover the same dates. To change a price from a date, end the old one and add a new one; “Copy” starts next year’s price from an existing one.

Changing a default amount or a price doesn’t change charges already on quotes or trips: each keeps the amount it was given. A charge type used on a quote, a trip or a special price can’t be deleted; deactivate it instead.
