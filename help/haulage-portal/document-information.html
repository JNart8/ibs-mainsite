    Appendix B

    Document Information

    This guide was produced from the current state of the IBS TMS client portal and reflects its screens and fields as of the date below. If the portal is updated after this date, some labels or steps may change.

    Version 1.0 — October 2026.

    Version 1.1 — November 2026. The portal is renamed IBS TMS (IBS Transport Management System). Places in the Origin and Destination lists show their short code.

    Version 1.2 — November 2026. New requests can give a quantity in bags or units and the truck type needed.

    Version 1.3 — November 2026. Quotes can include extra charges, listed under the total (section 3.3).

    Version 1.4 — November 2026. Requests have a Trip Type (One-way or Return empty), and quotes show the price of the empty return (sections 3.2 and 3.3).

    Version 1.5 — November 2026. Requests can have the Trip Type Multi-drop, for one load going to several places (section 3.2).

    Version 1.6 — November 2026. For a Multi-drop request you list the drops before the destination on the request form, and the request page shows the whole route (section 3.2).
